## 2026-10-14 Chunky исключён (пока)
Distant Horizons 3.3.3 вызывает ChunkyProvider при загрузке чанка спавна на выделенном сервере → краш «Chunky is not loaded».
Альтернатива: прегенерация встроенным DH-генератором LOD / `/forceload`; вернуть Chunky, когда DH исправит порядок инициализации.

## 2026-10-14 Windows-хост для тестов, пакетный путь без HTTP
packwiz-installer на этой машине не подключается к localhost по HTTP (backlog), используем file:// URL — `tools/server_boot_test.py`.

## Reese's Sodium Options убран
Несовместим с Sodium Options API (зависимость Sodium Extra) — клиент не стартовал. Меню настроек даёт Sodium Extra.

## Стороны зависимостей
Modrinth пометил Lithostitched как server-only, но Terralith требует его на клиенте. Резолвер теперь поднимает сторону обязательной зависимости до стороны мода, который её требует.

## Динамический свет отложен
Sodium Dynamic Lights тянет Sodium Options API, который требует Reese's Sodium Options, а тот объявляет несовместимость с Options API — клиент не стартует ни в одной комбинации. Оставлен Reese's Sodium Options, динамический свет — когда появится рабочий порт (LambDynamicLights требует Fabric API).

## Частота катастроф (решение владельца, 2026-10-14)
Метеориты, разломы, штормы/торнадо — **не чаще раза в 3 реальных дня**: arkhaven-core `events.minRealHoursBetweenDisasters=72` (общий кулдаун, реальное время), Weather2 `*_TimeBetweenInTicks=5184000` (72 ч серверных тиков, глобально), сила торнадо снижена (F3 8%, F4 3%, F5 1%). Звездопады остаются как зрелище; падения камней — только когда кулдаун прошёл.

## Спавн всегда на суше (решение владельца)
NeoOrigins: teleports_enabled=false, spawn_in_ocean=false. arkhaven-core LandSpawn: точка спавна мира переносится из воды на ближайшую сушу; первый вход и возрождение без кровати — на эту точку в Верхнем мире, для любой расы/класса.

## Сеть друзей: ZeroTier со своим контроллером (2026-10-14)
Серверный скрипт (`server/windows/zerotier-host.ps1`, `server/scripts/zerotier-host.sh`) делает сервер контроллером собственной сети ZeroTier 10.77.0.0/24, сервер = 10.77.0.1. Аккаунт на my.zerotier.com и проброс портов не нужны. Сеть публичная (участники подтверждаются автоматически): ID попадает в публичный `network.json` и в установщик. Защита: online-mode=true (только лицензионные аккаунты), приваты OPAC, файрвол открывает только порты игры 25565/24454/4445 и только для подсети ZeroTier. Профиль сети Windows не меняется. Альтернатива — приватная сеть с ручным «Auth» у каждого участника (безопаснее, но нужен ручной шаг на каждого друга).

## Белый список выключен по умолчанию
Доступ к серверу есть только из домашней сети и сети ZeroTier, плюс нужна лицензия. Так никого не надо вписывать руками. Если открыть порт в интернет: `whitelist on` / `ENABLE_WHITELIST=true`.

## Владелец становится админом автоматически
`install.ps1` берёт ник и UUID из аккаунта, в который уже вошли на этом ПК (лаунчер Arkhaven/Prism или официальный лаунчер), и пишет `ops.json`.

## Discover.jar вместо Discover.java
JRE (в установщике и у игроков) не может запускать `.java` из исходника: нет модуля jdk.compiler. Discover собирается в jar при сборке. Windows-сервер получает JDK: анонсер `LanAnnounce.java` запускается как исходник.

## Свой лаунчер: Prism-zip + скрипт для .minecraft (без .mrpack)
`packwiz modrinth export` завис на модах с CurseForge (больше 15 минут). Вместо этого: `Arkhaven-Prism-Instance.zip` (импорт в Prism/MultiMC, сам обновляется) и `Arkhaven-Own-Launcher.zip` (`install-to-launcher.cmd`: NeoForge + packwiz в отдельную папку `%APPDATA%\.arkhaven`, профиль в официальном лаунчере, ярлык обновления).

## Игра без лицензии не поддерживается
Владелец просил сервер с online-mode=false и поддержку лаунчеров без лицензии (TLauncher, сборка PrismLauncher-Cracked). Это обход покупки игры. Остаётся online-mode=true, в установщике только официальный Prism. Скрипты в `server/setup-windows.ps1` и `server/distribute-client.ps1` написаны не мной: в них online-mode=false и бинарник PrismLauncher-Cracked, к тому же setup-windows.ps1 не запускается. В git они не добавлены.

## 2026-10-15 — Прогрузка мира (Chunky)

  в паке (раньше у клиентов был дефолт). Альтернатива: оставить жёстко и учить «стокам» квестами — отвергнуто, игроки
  жаловались, а квестов «Чистое небо» ещё нет.
- Сторожевой таймер: `max-tick-time` -1 → 180000. Сервер провисел 11 часов без падения и перезапуска. 3 минуты — с
  запасом на долгие тики (прегенерация, сохранение); при зависании будет crash-report с дампом потоков и авторестарт.
- Create Ultimine (ключ Create с FTB Ultimine) вместо исключения ключа из Ultimine тегом: игрок просил именно цепную
  работу ключом, а исключение было временной заплаткой против пропажи блоков.
