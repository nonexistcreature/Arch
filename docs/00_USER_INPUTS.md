# 00 — Данные от владельца (заполнить один раз, ~10 минут)

> Это единственное, что агенту нужно от тебя до финала. Всё остальное он сделает сам.
> Пустые поля агент заполнит значениями по умолчанию (указаны в скобках) и запишет это в отчёт.

## Уже известно

| Параметр | Значение |
|---|---|
| Где сервер | Отдельный домашний компьютер, работает постоянно |
| Самый слабый ПК игроков | Средний: ~16 ГБ ОЗУ, видеокарта уровня GTX 1660 / RX 580 |
| Игроков одновременно | 5–8 |
| Язык квестов и подсказок | Русский + английский (русский по умолчанию) |

## Обязательно (без этого не будет деплоя)

1. **Ники Minecraft (Java) всех игроков** — для белого списка. Админ — кто?
   ```
   admin: 
   players: 
   ```
   ⚠ У каждого игрока должна быть лицензионная Minecraft: Java Edition (вход через Microsoft).

2. **Серверный ПК** (агент проверит сам по SSH, но заполни что знаешь):
   - ОС: (по умолчанию — поставить Ubuntu Server 24.04 LTS, если машина свободна)
   - Процессор / ОЗУ / диск: 
   - Минимум для этой сборки: **32 ГБ ОЗУ**, 6+ ядер с хорошей одноядерной скоростью
     (уровень Ryzen 5 5600 / Core i5-12400 и выше), **NVMe SSD 250+ ГБ свободно**, проводной интернет.
     Если ОЗУ 16 ГБ — сборка запустится, но агент урежет дальность прорисовки сервера и число модов.
   - IP компьютера в домашней сети (например `192.168.1.50`): 
   - SSH: логин + вход по ключу настроен? (если нет — агент даст одну команду, которую нужно
     выполнить на сервере, чтобы добавить ключ)

3. **Сеть / доступ друзей извне:**
   - Есть ли доступ к настройкам роутера (проброс порта)? да / нет / не знаю
   - Провайдер даёт «белый» IP? (не знаю — агент проверит сам)
   - Если проброс невозможен — агент настроит туннель **playit.gg** (бесплатно; понадобится
     один раз зайти по ссылке и привязать агент к аккаунту — это займёт 1 минуту).

4. **GitHub-аккаунт** (по желанию, но очень рекомендуется): репозиторий для сборки и
   бесплатный хостинг файлов автообновления. Если нет — агент будет раздавать обновления
   с самого домашнего сервера.
