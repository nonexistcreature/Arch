# 03 — Интеграция: как моды сшиваются в одну игру

Цель: у каждого игрока своя любимая система, но системы **пересекаются в нескольких ключевых
точках («рукопожатиях»)**, поэтому выгодно общаться и делать общие проекты. При этом никто
не заблокирован наглухо: у каждого рукопожатия есть соло-обход (дороже в 2–3 раза или медленнее).

## 1. Принципы

1. **3–5 рукопожатий на тир**, не больше. Не превращаем сборку в expert-pack.
2. **Сначала встроенные связи модов** (они уже сбалансированы авторами), потом KubeJS.
3. **Соло-обход обязателен** для всего, что ниже тира 4. Пример: парящий камень можно найти в
   мире (как задумано модом) ИЛИ получить ритуалом мага (возобновляемо).
4. **Подсказки в тултипах:** у предметов-рукопожатий строка «Ценится у: инженеров (дирижабли)»
   (KubeJS client tooltip). Игрок сразу видит, кому это нести.
5. **Никаких Game Stages и жёстких замков** — прогрессия естественная (рецепты + квесты).

## 4. Рукопожатия через KubeJS (реализовать; ~30–45 штук)

Ниже обязательный минимум. Каждое: рецепт(ы) + тег + тултип + квест в двух главах.
Точные id предметов агент берёт из дампа реестра (`tools/registry_dump`), не по памяти.

### Транспорт и цитадели
1. **Парящий камень Aeronautics** (найти точный id «magic floating rocks» в моде): оставить
   природный источник + добавить возобновляемый рецепт мага (камень + Source в Imbuement
   Chamber Ars **или** руна Botania). → маги нужны строителям цитаделей.
2. **Пропитанная ткань** (новый предмет `arkhaven:waxed_canvas`): шерсть/лён + воск пчёл
   (Productive Bees) **или** пластик Mekanism (тех-обход). Нужна для оболочек воздушных шаров
   (добавить как альтернативный/дополнительный ингредиент, не ломая базовые рецепты Aeronautics
   ранних тиров — только для крупных оболочек).
3. **Лётная смазка** (`arkhaven:aero_lubricant`): рыбий жир (Create mixing из рыбы Tide) **или**
   смазка TFMG/IE. Нужна для двигателей/пропеллеров среднего тира.
4. **Драконья обшивка**: чешуя Dragon Mounts + сталь → броня/бронеплиты для боевых кораблей
   (Create Big Cannons), тех-обход: Mekanism-сплав, ×3 дороже.

### Защита от катастроф
5. **Кристаллы оберега T1/T2/T3** (`arkhaven:ward_crystal_t1..t3`) — топливо Генератора оберега:
   - T1: аметист + метеоритная пыль → Create Mixing (нагрев) **или** Ars Imbuement;
   - T2: + Source Gem / мана-алмаз **и** Mekanism-сплав (основной рецепт — тех + магия вместе);
     соло-обходы: только тех или только магия, но ×3 по стоимости;
   - T3: + экзотическая материя Коллайдера.
6. **Фильтр чистого воздуха**: Airborne-стоки + рецепт «очищающего тотема» мага
   (Botania/Ars) — если Airborne поддерживает свои стоки через теги/датапак, повесить тег.
7. **Громоотводы и метеостанция** — квестовая связка Weather2 (радар, сенсор торнадо, дефлектор)
   с Create (питание/сигналы) — рецепты дефлектора удорожить до T2, чтобы он был целью.

### Еда, баффы, магия
8. **Блюда с баффами** (KubeJS добавляет эффекты к 10–15 блюдам FD/Let's Do), например:
   «Шахтёрский пирог» — Спешка II 5 мин; «Рагу храбреца» — Сопротивление I + огнестойкость 5 мин;
   «Чай сосредоточенности» (HerbalBrews) — регенерация маны Iron's Spells; «Ужин под звёздами» —
   Удача 20 мин. → повара нужны воинам, шахтёрам, магам.
9. **Звёздный карп** (своя рыба через датапак Tide): ловится только ночью во время метеоритного
   дождя. Нужен в ритуале Occultism/Ars и в «Ужине под звёздами». → рыбаки нужны магам и поварам.
10. **Метеоритное железо** (с событий и мест падения) → оружие высоких тиров TaCZ, фокусы магии,
    кристаллы оберега. → исследователи нужны всем.
11. **Зелья и ингредиенты из существ** Alex's Mobs → алхимия Ars/Iron's (через теги).

### Город и строительство
12. MineColonies-колония производит декор Domum Ornamentum, стекло, бетон, зачарованные книги
    → строители и маги. Колония потребляет еду повара и инструменты инженера.
13. Схематики: в сундуках данжей — свиток «Чертёж» (KubeJS-лут), который выдаёт готовую
    Create-схематику красивого здания/корабля (схематики собрать в `pack/schematics/`, только
    свои или с открытой лицензией).

### Алхимия, расы, классы (подробно в `10_RPG_DANGER.md`)
14a. Свои зелья (таблица 10 §3): каждое собирается из ингредиентов **двух-трёх разных ролей**
     → алхимик торгует со всеми, а все нуждаются в алхимике (Тишина, Чистое дыхание, Свинцовая кровь…).
14b. Умения классов, которых нет в атрибутах, — теги игрока → поведение через KubeJS
     (Кулинар: дольше баффы еды; Заводчик: двойня; Садовод: урожай). Помечать `// SKILL:`.
14c. Расы слегка усиливают «свои» рукопожатия (Морской народ — удача Tide, Драконид — яйца,
     Механоид — смог), но не являются обязательным условием ни для одного рецепта.

### Мегапроекты (Modular Machinery Reborn, JSON)
14. **Кольцевой коллайдер** — огромный кольцевой мультиблок (радиус от 24 блоков, из корпусов
    Mekanism/IE + стабилизаторов магии). Вход: антиматерия Mekanism SPS + мана/Source + энергия.
    Выход: `arkhaven:exotic_matter` → обереги T3, Терраформер, финал квестов.
15. **Терраформер** — мультиблок, который за энергию + экзотическую материю меняет биом в радиусе
    (через `/fillbiome`, вызываемый KubeJS по завершении рецепта/событию машины). Радиус 32–64.
16. **Климатическая обсерватория** (опц.) — даёт прогноз событий на 3 дня вперёд.

Если MMR нет/сломан на 1.21.1 — те же машины в `arkhaven-core` как простые мультиблоки
(проверка паттерна + рецепт в датапаке).

## 6. Анти-гринд: конфиги по модам (агент выставляет и документирует в `docs/reports/configs.md`)

- **FTB Ultimine**: до 64 блоков, малый расход голода.
- **Руды**: умеренно увеличить размер жил (+25–50%) у руд модов, Almost Unified против дублей.
- **AE2**: каналы — режим `infinite` (уютная сборка; инженерам хватит других задач).
- **MineColonies**: ускорить исследования (×0.5 времени, если есть конфиг), смягчить штрафы счастья.
- **Dragon Mounts**: время вылупления сократить ~в 2 раза.
- **Tide**: мини-игра по умолчанию лёгкая; в квестах сказать, где её отключить в настройках.
- **Waystones**: дешёвая телепортация (XP), Warp Stone доступен рано.
- **Сон**: `playersSleepingPercentage` ≈ 34 (2–3 спящих из 8), фантомы выключены (`doInsomnia false`).
- **Смерть**: надгробие GraveStone, вещи не теряются; часть опыта сохраняется.
- **Спаун мобов**: не урезать враждебных до нуля (нужны цели для оружия), но кап держать под контролем ради TPS.

## 7. Мод `arkhaven-core` (NeoForge 21.1.x, Java 21, ModDevGradle)

Минимальный свой мод. Всё, что можно сделать KubeJS/датапаком, делаем там.
Предметы (кристаллы, метеоритное железо, экзотическая материя, ткань, смазка) регистрирует
**KubeJS startup**, мод ссылается на них через теги (`#arkhaven:ward_fuel/t1` и т.д.).

### Блоки
- `ward_generator_t1/t2/t3` — BlockEntity: слот топлива (тег `ward_fuel/tN`), опц. вход FE
  (capability), радиус 32/64/128 (конфиг), расход: 1 кристалл на N минут работы (только пока
  в зоне есть игрок или идёт событие), выключение редстоуном, полупрозрачный купол частиц
  (клиент, отключаемый). Защищает в радиусе: снимает разрушение блоков взрывами
  (`ExplosionEvent.Detonate`), сжигает метеориты в воздухе (лут падает рядом, вне зоны), с T2 —
  подавляет спаун мобов из разломов. Jade-подсказка: радиус, топливо, время.
- (стретч) `citadel_heart` — засчитывает квест, если находится на летящем Sable-объекте выше Y 180.
- `hearth_stone` («Камень очага») — запасной способ отметить дом, если API OPAC недоступен:
  создаёт безопасную зону радиусом 48 блоков (см. фильтр ниже). Один на игрока (конфиг).

### Фильтр безопасных зон и мирные правки (подробно `10_RPG_DANGER.md` §6)
- Запрет **естественного** спауна враждебных мобов (`MobCategory.MONSTER` + тег
  `#arkhaven:always_blocked_near_home`) в зоне 0: Гавань (радиус из конфига), приваты OPAC
  (+48 блоков; soft-dependency на OPAC API), Камни очага, границы колоний MineColonies (если есть API).
  Мобы событий (разломы) не фильтруются, но разломы не открываются внутри зоны 0.
- Взрывы криперов не разрушают блоки (урон сущностям остаётся).
- Actionbar-подсказка при переходе между зонами 1/2/3 (можно и в KubeJS — выбрать проще).
- GameTest: в зоне 0 при ускоренном времени ночью естественных враждебных мобов = 0;
  взрыв крипера не меняет блоки.

### Сущности
- `meteor` — летит по дуге с огненным шлейфом; при ударе — взрыв (сила по конфигу/интенсивности),
  небольшой кратер с `arkhaven:meteorite_ore` и лутом. Уважает обереги и (при интенсивности ≤ 1)
  приваты OPAC: не падает в приватные чанки без оберега, а уходит в сторону.
- `rift` — визуальный разлом (частицы), выпускает волны мобов из тега
  `#arkhaven:rift_spawns` (датапак; валидатор проверяет, что все id существуют), 3–5 минут,
  после закрытия — «осколки разлома» (лут для магии).

### Режиссёр событий (Event Director) — серверная логика
- Тикает раз в 20 с, хранит состояние в `SavedData`.
- Учитывает: интенсивность 0–3, онлайн-игроков и их базы (приваты OPAC / точки спавна),
  льготный период (по умолчанию 7 игровых дней с первого входа), «обучен ли» сервер событию
  (тег/скорборд, который KubeJS ставит при выполнении учебного квеста), режим «отпуск».
- **Никогда не запускает** событие, если никого нет онлайн, идёт льготный период, включён отпуск.
- **Первое событие каждого типа — учебное**: безопасное, далеко от построек, с подробной подсказкой.
- Предупреждения: чат + титр + босс-бар с обратным отсчётом + звук; метеоритный удар по базе —
  за 10 реальных минут, направление показывается частицами в небе.
- Типы: `METEOR_SHOWER` (красиво + мелкие падения в дикой местности, лут), `METEOR_STRIKE`
  (крупный метеорит рядом с базой), `RIFT_NIGHT` (ночью у игроков), объявление кровавой луны
  (сама луна — Enhanced Celestials).
- Частоты и сила по интенсивности:
  - 1 (мягко, по умолчанию): `METEOR_STRIKE` не чаще 1 раза за ~6 ч суммарного онлайна и падает
    «рядом» — в 60–120 блоках от базы, вне приватов (зрелище + лут, ничего не ломает);
    ночь разломов ~1 на 10 ночей; метеоритные дожди часто (в основном награда).
  - 2 (серьёзно): удар может прийтись в приват без оберега; разломы ~1 на 6 ночей.
  - 3 (жёстко): чаще и сильнее; рассчитано на игроков, которые хотят оборонять базы.
- Команды: `/arkhaven status | forecast | event <type> [player] | vacation on|off | intensity <0-3>`
  (управление — уровень OP 2). Предмет «Звёздный атлас» (KubeJS) показывает прогноз игрокам.
- Конфиг: `config/arkhaven-common.toml` — все числа выше.

### GameTests (обязательно)
1. Взрыв внутри радиуса активного оберега не ломает блоки; снаружи — ломает.
2. Метеорит вне оберега создаёт кратер с рудой; над оберегом — сгорает, блоки целы.
3. Режиссёр не запускает событие при 0 игроков / в отпуске / в льготный период.
4. Первое событие типа — учебное (без разрушений).
5. Все id в `#arkhaven:rift_spawns` и `#arkhaven:ward_fuel/*` существуют.

## 8. KubeJS: структура и соглашения

```
kubejs/
├─ startup_scripts/  items.js, blocks.js (свои предметы/блоки), food_props.js,
│                    effects.js (свои эффекты и зелья), stack_sizes.js (зелья по 8)
├─ server_scripts/
│  ├─ recipes/       create.js, mekanism.js, magic.js, food.js, aero.js, handshakes.js, removals.js
│  ├─ tags/          unify.js, food_tags.js, arkhaven_tags.js
│  ├─ loot/          dungeon_blueprints.js, meteor_loot.js
│  ├─ quests/        hooks.js (засчёт кастомных задач, флаги «обучен событию»)
│  ├─ festivals.js   сезонные праздники (Serene Seasons)
│  ├─ food_buffs.js
│  ├─ alchemy.js     рецепты своих зелий (котёл Toil and Trouble / варочная стойка)
│  ├─ skills.js      поведение умений классов по тегам игрока (// SKILL:)
│  ├─ set_bonuses.js бонусы за полный комплект брони
│  └─ zones.js       подсказки о зонах опасности (если не в arkhaven-core)
├─ client_scripts/   tooltips.js («Ценится у…»), emi_hide.js (скрыть мусор/технические предметы)
└─ assets/arkhaven/lang/ ru_ru.json, en_us.json   (все строки!)
```

- Удаления рецептов — только с причиной в комментарии.
- Каждое рукопожатие помечено комментарием `// HANDSHAKE: <кто> -> <кому>` — валидатор
  `tools/handshake_report.py` строит по ним таблицу в `docs/reports/handshakes.md`.

## 9. Сезонные праздники (повторяемый контент для «вернулись через месяц»)

Serene Seasons меняет сезон каждые ~24 игровых дня. На старте сезона KubeJS открывает
повторяемую главу праздника (FTB Quests repeatable) с кооперативными целями и косметическими
наградами:
- Весна — «Праздник сева» (посадить N видов, вывести пчёл);
- Лето — «Ярмарка ремёсел» (выставка машин/кораблей, гонка на Aeronautics по контрольным точкам);
- Осень — «Праздник урожая» (Гранд-ужин, тыквенные блюда, вино);
- Зима — «Огни зимы» (украсить город, рыбалка на льду, защита от метелей Weather2).
