# 06 — Клиент: красота, интерфейс, звук, производительность

Целевое железо (самый слабый игрок): ~16 ГБ ОЗУ, GTX 1660 / RX 580 (6–8 ГБ VRAM), 1080p, SSD.
Цель: **красиво по умолчанию, но играбельно на среднем ПК** + пресеты для слабых и мощных.

## 1. Рендер и дальность

- Sodium + Iris (официальные сборки под NeoForge) + Sodium Extra + Reese's Sodium Options.
- **Distant Horizons**: LOD-ландшафт до горизонта; ванильная дальность 8–12 чанков (выше
  смысла нет). Сервер раздаёт LOD (не надо исследовать всё самому).
- **Separate Sable Render Distance** — чтобы корабли/самолёты Aeronautics были видны дальше
  обычной дальности вместе с DH. **Iris Veil Compat** — чтобы детали Aeronautics (крылья,
  стёкла, следы) корректно рисовались под шейдерами (у самого Aeronautics есть визуальные
  проблемы с Iris без этого моста).
- Шейдеры: **Complementary Reimagined** (по умолчанию) и **Complementary Unbound** (ультра) +
  **Euphoria Patches** (аддон с доп. эффектами; все опции по умолчанию выключены — включить
  подобранный набор: красивые облака, туман, отражения в воде, без тяжёлого).
  Complementary совместим с Distant Horizons.
- Проверить совместимость шейдеров с: Weather2 (облака/туман метели), Aeronautics/Veil,
  Create (Flywheel), TaCZ (Veil ≥ 3.1.2), DH. Проблемы — в `docs/reports/visual_issues.md`.

## 2. Пресеты графики

| Пресет | Для кого | Шейдер | Профиль | DH (чанков LOD) | Дальность | Частицы/анимации |
|---|---|---|---|---|---|---|
| Лёгкий | слабые ПК/ноутбуки | выкл. | — | 64 | 8 | урезаны |
| Средний | GTX 1060–1660 | Reimagined | Low/Medium | 96 | 10 | все лёгкие |
| **Красиво** (по умолч.) | GTX 1660 Super / RTX 2060+ | Reimagined + Euphoria (лёгкий набор) | Medium/High | 128 | 10 | все |
| Ультра | RTX 3070+ | Unbound + Euphoria | High/Ultra | 256 | 12 | все |

Как переключать (реализовать оба способа):
1. **В установщике:** страница выбора пресета; предвыбор по видеокарте (Inno Setup Pascal-скрипт
   читает `Win32_VideoController` — имя и объём памяти) с понятным описанием.
2. **Ярлык «Arkhaven — сменить графику»** (маленький скрипт/утилита из `launcher/`): пока игра
   закрыта, переписывает набор файлов пресета (`options.txt` — только графические ключи,
   `config/iris.properties`, профиль шейдера, `config/sodium-*.json`, конфиг DH).
   Внутри игры профили Complementary также меняются в настройках шейдера.
FPS-цели — в `01_VISION.md` §Бюджеты. Финальную проверку FPS на реальной видеокарте делает
владелец по чек-листу из `HANDOFF.md` (в CI нет GPU — см. 08).

## 3. Ресурспаки (только через packwiz, без бинарников в git)

- **Fresh Animations** (+ Entity Model Features + Entity Texture Features) — живые мобы.
- Better Leaves (пышная листва), аккуратный ванильный «Stay True»-стиль или аналог —
  **никаких высокорезолюционных паков**: 600 модов в ванильном стиле, иначе разнобой.
- Единый, читаемый GUI: проверить «тёмный режим» GUI с поддержкой модов; если ломает экраны
  модов — оставить ванильный GUI.
- ⚠ **Кириллица:** любой пак со своим шрифтом должен поддерживать русский. Проверять скриншотом.
- Порядок паков фиксируется в шаблоне `options.txt` (`resourcePacks:[...]`).

## 4. Интерфейс (HUD) — «всё ровно, чётко, удобно»

Требования:
1. Никаких наложений элементов HUD на 1920×1080 (масштаб GUI 2 и 3) и 1366×768 (масштаб 2).
   Проверять **скриншотами** в тестовом клиенте (08 §5) и глазами (агент умеет смотреть картинки).
2. Раскладка по умолчанию:
   - центр-низ: хотбар, Overflowing Bars, AppleSkin (насыщение);
   - правый верх: миникарта Xaero (компактная, с биомом и временем, без лишнего);
   - центр-верх: Jade (компактный, полупрозрачный, только при наведении);
   - левый верх: закреплённые квесты FTB (до 3);
   - полосы маны Ars / Iron's Spells / Botania — не друг на друге (развести по краям хотбара);
   - тосты: Toast Control — только важные, быстрее исчезают;
   - эффекты (баффы/дебаффы): компактные иконки с таймерами у правого края, не под миникартой;
   - кулдауны способностей расы (NeoOrigins) — рядом с хотбаром, не поверх полос маны;
   - индикатор троса/крюка — только когда крюк в руке;
   - тревоги погоды/событий — босс-бар сверху (один стиль для всех событий arkhaven-core).
3. Тултипы: Legendary Tooltips (рамки по редкости) + Enchantment Descriptions + строки
   «Ценится у…» из KubeJS.
4. **Без конфликтов клавиш.** С 500+ модами это обязательная работа: скрипт
   `tools/check_keybinds.py` разбирает `options.txt` и сообщает дубли; итоговая раскладка
   без конфликтов фиксируется в шаблоне, а шпаргалка клавиш — в главе 0 квестов.
5. Главное меню **FancyMenu**: логотип Arkhaven, фон-панорама из реального мира сборки,
   кнопки «Играть» (сразу на сервер), «Одиночная игра», «Настройки», «Моды», «Выход».
   Экран загрузки **Drippy**: тематический фон + ротация подсказок (RU/EN).
6. Traveler's Titles — красивые титры при входе в биом/данж/измерение.

## 5. Атмосфера и звук

- Частицы/анимации: Subtle Effects, Particle Rain, Visuality, Falling Leaves, динамический свет
  (что есть под NeoForge), Not Enough Animations, True Falling Stars.
- Звук: Sound Physics Remastered (эхо в пещерах, глушение за стенами — проверить с голосовым
  чатом, у SVC есть совместимость), AmbientSounds (звуки биомов), Presence Footsteps (если есть
  под NeoForge). Громкости по умолчанию сбалансировать (мобы/погода не громче музыки).
- Голосовой чат Simple Voice Chat: по близости, push-to-talk по умолчанию (клавиша в шпаргалке).

## 6. Производительность клиента

- Моды из `02_MODLIST.md` §B. Java 21, **8 ГБ** heap (`-Xmx8G -Xms4G`), G1 с проверенными
  флагами для модпаков; не ставить больше 10 ГБ на 16-гиговых машинах.
- ModernFix (динамические ресурсы), FerriteCore — снижение памяти; цель — загрузка до меню ≤ 3 мин.
- Тяжёлое под контролем: частицы Weather2 (настройка плотности для пресетов), Fresh Animations
  (ок), DH (поток генерации LOD — средний), Create/Flywheel (бэкенд инстансинга, при шейдерах —
  совместимый режим).
- Профилирование: spark (клиент) — сценарий бенчмарка (см. 08 §6), владелец запускает его один раз
  на финале, агент по логу подстраивает пресеты (если владелец присылает лог).
