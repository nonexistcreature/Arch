# Arkhaven — как начать играть

Нужен аккаунт Minecraft (Java Edition) с входом через Microsoft и Windows 10/11.
Сервер находится сам: дома — через локальную сеть, издалека — через сеть друзей ZeroTier.

## Способ 1. Установщик (проще всего)

1. Скачай `Arkhaven-Setup.exe` (Releases на GitHub: https://github.com/nonexistcreature/Arch/releases).
2. Запусти. Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
3. Пресет графики уже выбран по видеокарте. Если ты играешь **не у владельца сервера дома**, оставь галочку
   «подключить сеть друзей (ZeroTier)»: Windows один раз спросит права администратора.
4. Войди в аккаунт Microsoft и нажми «Играть». Первый раз скачается ~1 ГБ модов (5–15 минут),
   потом игра сама зайдёт на сервер.

## Способ 2. Prism Launcher / MultiMC

«Добавить экземпляр» → «Импорт» → `Arkhaven-Prism-Instance.zip`.
Сборка обновляется сама перед каждым запуском, сервер ищется сам.
Для игры издалека один раз запусти **`Arkhaven-ZeroTier.cmd`** из Releases (двойной клик → «Да»).

## Способ 2½. Любой лаунчер, который понимает .mrpack (Modrinth App, Prism, ATLauncher, GDLauncher…)

Скачай `Arkhaven-<версия>.mrpack` из Releases и импортируй его в лаунчер: «Добавить / Импорт / Import modpack»
или просто перетащи файл в окно лаунчера. Лаунчер сам скачает Minecraft 1.21.1, NeoForge 21.1.259 и все моды
(Modrinth и CurseForge), настройки и квесты уже внутри. Памяти дай 8–12 ГБ.
Сервер «Arkhaven» будет первым в списке «Сетевая игра».
Учти, что .mrpack не обновляется сам. Когда выйдет новая версия, импортируй новый файл
или используй Способ 1 или 2: там обновление автоматическое.
Если ты играешь издалека, один раз запусти **`Arkhaven-ZeroTier.cmd`** из Releases (двойной клик → «Да»).

## Способ 3. Официальный лаунчер или другой лаунчер с обычной папкой .minecraft

1. Распакуй `Arkhaven-Own-Launcher.zip`, запусти `install-to-launcher.cmd`.
2. Скрипт ставит NeoForge 21.1.259, скачивает сборку в отдельную папку `%APPDATA%\.arkhaven`
   (твои миры и моды не трогаются), подключает ZeroTier и добавляет профиль «Arkhaven» в официальный лаунчер.
3. В другом лаунчере выбери версию `neoforge-21.1.259`, папку игры `%APPDATA%\.arkhaven` и дай 8–12 ГБ памяти.
4. Перед игрой после обновлений запускай ярлык «Arkhaven — обновить».

## Только подключиться к сети друзей

`Arkhaven-ZeroTier.cmd` из Releases — двойной клик, «Да» на запрос прав. Сам поставит ZeroTier (если его нет),
подключится к сети друзей и откроет только порт обнаружения сервера. Повторный запуск безопасен.
Нужен, только если ты играешь **не** из дома владельца сервера.

## Графика

Ярлык «Arkhaven — графика»: Быстро / Сбалансировано / Красиво / Максимум (только в установщике).
В игре: Настройки → Видео → Шейдеры.

## Клавиши

`L` — квесты, `P` — умения, `M` — карта, `B` — рюкзак, `Caps Lock` (зажать) — голосовой чат, `V` — его настройки.
