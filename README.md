# Arkhaven — комплект ТЗ для автономной сборки

Это пакет документов, по которому Claude (Opus 5.5) в VS Code сам соберёт сборку Minecraft
на ~450–600 модов, протестирует её, сделает `.exe`-установщик для друзей и развернёт сервер
на твоём домашнем компьютере.

## Как запустить (5 минут твоего времени)

1. Распакуй папку `arkhaven/` куда удобно и открой её в VS Code.
2. Заполни `docs/00_USER_INPUTS.md` (ники игроков, данные серверного ПК, сеть).
   Можно частично — агент спросит недостающее одним списком в `HANDOFF.md`.
3. На серверном ПК должен быть доступ по SSH с твоего компьютера (агент подскажет команду,
   если ключ не настроен).
4. Открой Claude Code в этой папке и дай задачу:

   > Прочитай CLAUDE.md и все документы в docs/. Выполни проект Arkhaven полностью по
   > docs/09_ROADMAP.md, работая автономно: исследуй, собирай, тестируй, исправляй,
   > разворачивай. Веди PROGRESS.md. Меня не жди — всё, что нужно только от меня,
   > складывай в HANDOFF.md и продолжай. В конце подготовь HANDOFF.md по шаблону.

5. Вернись, когда в `HANDOFF.md` появится раздел «Как зайти». Работа длинная (несколько
   десятков часов работы агента, разбитых на сессии): если сессия прервалась — просто снова
   попроси «продолжай по PROGRESS.md».

## Важно знать заранее

- У каждого игрока должна быть лицензионная Minecraft: Java Edition (вход через Microsoft).
- Серверному ПК нужно ~32 ГБ ОЗУ для комфортной игры 5–8 человек на такой сборке.
- Windows покажет предупреждение SmartScreen при первом запуске неподписанного exe —
  это нормально («Подробнее → Выполнить в любом случае»).
- FPS на реальных видеокартах агент проверить не может (у него нет GPU) — в конце будет
  2-минутный чек-лист, после которого он подстроит пресеты графики.
