# HANDOFF — для владельца

> Документ дополняется по ходу работы. Финальная версия — в конце проекта (фаза 7).

## Нужно от владельца

1. **GitHub-репозиторий.** Создай пустой репозиторий (например `arkhaven`) и пришли ссылку. Дальше:
   - я добавлю его как `origin` и сделаю `git push` — Windows один раз откроет окно входа GitHub в браузере, подтверди;
   - в репозитории: **Settings → Pages → Source: GitHub Actions** (одна галочка).
   После этого сборка публикуется сама: ссылка на пакет будет `https://<ник>.github.io/<репо>/pack.toml`,
   а `Arkhaven-Setup.exe` и `Arkhaven-Server-Kit.zip` будут появляться в Releases при каждой новой версии.
2. **Где сервер:** ноутбук на Linux или твой ПК на Windows — инструкция в `server/КАК_РАЗВЕРНУТЬ.md`
   (архив `launcher/dist/Arkhaven-Server-Kit.zip`). Если хочешь, чтобы я поставил всё на ноутбук сам — дай его IP и SSH-доступ.
3. **Ники игроков** для белого списка и кто админ.
4. **Только если друзья не в твоей домашней сети:** доступ к роутеру (проброс 25565/TCP, 24454/UDP) или аккаунт playit.gg.

В локальной сети ничего настраивать не нужно: сервер сам объявляет себя, а лаунчер находит его и подключается.

## Что уже установлено на этой машине (для разработки)

Всё лежит **внутри папки проекта** `tools/bin/` (в git не попадает):
JDK 21 (Temurin), packwiz, NeoForge-установщик, packwiz-installer-bootstrap,
Inno Setup 7.1 (установлен «для текущего пользователя» в `tools/bin/inno`, удаляется через
«Приложения» → Inno Setup), кеш Prism Launcher и JRE. Python-пакет `pyyaml`.
Тестовый клиент — `tests/client_run/` (HeadlessMC, без окна).
⚠ Один раз HeadlessMC по умолчанию поставил NeoForge в твою папку `%APPDATA%\.minecraft`. Я это откатил:
профиль «NeoForge» убран из официального лаунчера (копия старого файла — `tests/launcher_profiles.backup.json`),
версии перенесены в папку проекта. В `%APPDATA%\.minecraft\libraries` могли остаться скачанные библиотеки —
это просто кеш, он ничего не меняет (можно не трогать).
Тестовый сервер — `tests/server_run/` (только 127.0.0.1, offline-режим, запускается и останавливается тестом).
