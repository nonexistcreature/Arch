# HANDOFF — для владельца

> Документ дополняется по ходу работы. Финальная версия — в конце проекта (фаза 7).

## Нужно от владельца (одним списком)

Без этих данных я сделал всё, что мог: сборка, квесты, установщик и серверные скрипты готовы и
проверены локально. Чтобы друзья смогли зайти, нужно **10 минут** твоего времени:

1. **Ники Minecraft Java** всех игроков и кто админ → впиши в `docs/00_USER_INPUTS.md` §1.
   (Попадут в белый список `WHITELIST`/`OPS` в `/opt/arkhaven/compose/.env`.)
2. **Серверный ПК:** IP в домашней сети и SSH-доступ.
   Если вход по ключу не настроен — выполни на сервере одну команду (ключ агента пришлю по запросу)
   или просто дай логин; после этого я сам запущу `server/scripts/preflight.sh` и `install.sh`.
3. **Доступ друзей извне** — одно из:
   - есть доступ к роутеру → проброс портов `25565/tcp` и `24454/udp` на серверный ПК
     (+ я настрою бесплатное имя DuckDNS — понадобится войти на duckdns.org и прислать токен);
   - нет доступа / «серый» IP → playit.gg: один раз перейти по ссылке, которую выдаст агент, и привязать.
4. **GitHub** (желательно): аккаунт/репозиторий для бесплатной раздачи обновлений сборки (GitHub Pages).
   Без него обновления будут раздаваться с самого сервера (`--profile selfhost-pack`, порт 8080).

После этого: я впишу адрес сервера и URL пакета в `launcher/release.json`, соберу
`Arkhaven-Setup.exe` (`python launcher/build.py`) — и его можно раздавать друзьям.

## Что уже установлено на этой машине (для разработки)

Всё лежит **внутри папки проекта** `tools/bin/` (в git не попадает):
JDK 21 (Temurin), packwiz, NeoForge-установщик, packwiz-installer-bootstrap,
Inno Setup 7.1 (установлен «для текущего пользователя» в `tools/bin/inno`, удаляется через
«Приложения» → Inno Setup), кеш Prism Launcher и JRE. Python-пакет `pyyaml`.
Тестовый клиент — `tests/client_run/` (HeadlessMC, без окна).
⚠ Один раз HeadlessMC по умолчанию поставил NeoForge в твою папку `%APPDATA%\.minecraft`. Я это откатил:
профиль «NeoForge» убран из официального лаунчера (копия старого файла — `tests/launcher_profiles.backup.json`),
версии перенесены в папку проекта. В `%APPDATA%\.minecraft\libraries` могли остаться скачанные библиотеки —
это просто кеш, он ничего не меняет (можно не трогать).
Тестовый сервер — `tests/server_run/` (только 127.0.0.1, offline-режим, запускается и останавливается тестом).
