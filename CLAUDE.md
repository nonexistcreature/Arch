# CLAUDE.md — Arkhaven: инструкция для агента

Ты (Claude Opus 5.5 в VS Code) собираешь **Arkhaven** — большую дружескую сборку Minecraft
(~450–600 модов) с готовым `.exe`-установщиком для игроков и сервером на домашнем ПК.
Владелец проекта подключится **только в самом конце**, чтобы зайти в игру и посмотреть.
Значит: ты сам исследуешь, собираешь, тестируешь, чинишь, разворачиваешь и документируешь.

## 0. С чего начать (каждая новая сессия)

1. Прочитай `PROGRESS.md` (создай, если нет). Это твоя память между сессиями: текущая фаза,
   что сделано, что сломано, следующие шаги. Обновляй его после каждого значимого шага.
2. Прочитай документы в `docs/` по порядку. Они — источник правды:
   - `docs/00_USER_INPUTS.md` — данные от владельца (ники, сервер, сеть). **Единственное место,
     где ты можешь ждать человека.** Если там пусто — делай всё, что не требует этих данных.
   - `docs/01_VISION.md` — цели, принципы, ключевые решения (версия, лоадер).
   - `docs/02_MODLIST.md` — список модов по системам, роли, альтернативы.
   - `docs/03_INTEGRATION.md` — как моды сшиваются между собой, KubeJS, свой мод `arkhaven-core`.
   - `docs/04_QUESTS.md` — квесты (RU+EN), структура, стиль текста.
   - `docs/05_WORLD_EVENTS.md` — мир, погода, катастрофы, загрязнение, защита.
   - `docs/06_CLIENT.md` — шейдеры, текстуры, HUD, звук, оптимизация, пресеты графики.
   - `docs/07_DISTRIBUTION_SERVER.md` — exe-установщик, автообновление, домашний сервер, бэкапы.
   - `docs/08_TESTING.md` — автоматические тесты и критерии прохождения.
   - `docs/09_ROADMAP.md` — фазы, порядок работ, Definition of Done.
   - `docs/10_RPG_DANGER.md` — расы (Origins), классы (деревья умений), алхимия, баффы/дебаффы,
     крюки-кошки, зоны опасности («мир спокойный, опасность — по желанию»).
3. Продолжай с первого незакрытого пункта в `docs/09_ROADMAP.md`.

## 1. Жёсткие правила

- **Версия:** Minecraft **1.21.1**, **NeoForge 21.1.x** (последний стабильный билд линии 21.1,
  закрепить точный номер в `pack.toml`), **Java 21**. Не переходи на 26.x, даже если кажется
  заманчиво — обоснование в `docs/01_VISION.md`.
- **Источник правды сборки — packwiz** (`pack/`). Не клади jar-файлы модов в git и никуда не
  перезаливай. Моды скачиваются из Modrinth/CurseForge в момент установки. Предпочитай Modrinth.
  Если мод на CurseForge запрещает стороннее скачивание и его нет на Modrinth — ищи замену
  или отметь в `docs/reports/blocked_mods.md`; не обходи запрет.
- **⛔ Запрещённые моды:** **Apotheosis и всё его семейство** (Apothic Enchanting, Apothic Spawners,
  Apothic Attributes, аддоны) — решение владельца, ломает игру. Мод, который тянет их как
  зависимость, тоже не ставится. Полный список запретов — `docs/02_MODLIST.md` §A.
- **Один мод на категорию.** Не ставь два мода, делающих одно и то же (две карты, два рюкзака,
  два вейнмайнера, два порта Alex's Mobs и т.д.). Таблица категорий — в `docs/02_MODLIST.md`.
- **Каждый мод должен оправдывать себя**: для кого он (роль игрока), какую петлю геймплея кормит,
  сколько стоит по FPS/TPS. Мод без ответа на эти вопросы не добавляется.
- **Мало гринда.** Никаких квестов «принеси 1000 X», никаких expert-рецептов на 9 вложенных
  крафтов. Подробные правила — `docs/04_QUESTS.md` §«Анти-гринд».
- **Мир спокойный по умолчанию.** Вблизи баз и спавна можно гулять без боя; сложные мобы —
  в диких землях, данжах и измерениях (зоны из `docs/10_RPG_DANGER.md` §6). Любой новый мод
  с враждебными мобами настраивается под эти зоны, прежде чем волна считается готовой.
- **Катастрофы не уничтожают мир за спиной игроков.** События идут только когда игроки онлайн,
  с предупреждением, и от каждого есть защита, которой учат квесты ДО первого события.
- **Каждое изменение проверяется** тестами из `docs/08_TESTING.md` (минимум: загрузка сервера
  без ошибок + валидатор ссылок). Нельзя переходить к следующей волне модов с красными тестами.
- **Ничего не ломать у владельца.** На домашнем сервере работай только в выделенном пользователе
  и каталоге (`/opt/arkhaven`), не трогай чужие сервисы, файрвол меняй минимально и документируй.
  Перед любым удалением мира — бэкап. Проверочные серверы с `online-mode=false` запускай  сделай для прода , там люди будут играть без лицензии или в формате пробы .
- **Тексты для игроков — на двух языках** (ru_ru по умолчанию, en_us). Никаких захардкоженных
  строк в квестах — только ключи перевода (см. `docs/04_QUESTS.md`).

## 2. Как работать

- Работай волнами (по 20–60 модов), после каждой: `packwiz refresh` → тест загрузки сервера →
  тест клиента (HeadlessMC) → валидаторы → коммит. Если волна ломает загрузку — бисекция
  (половина модов выключена → найти виновника), запиши в `docs/reports/conflicts.md`.
- Перед добавлением мода проверь через API Modrinth/CurseForge: есть ли версия для
  `1.21.1 + neoforge`, когда обновлялась, зависимости, сторона (client/server/both),
  известные несовместимости (страница мода, issues). Неофициальные порты допустимы, если
  мод важен и порт живой; отметь `⚠ порт` в `docs/reports/modlist_resolved.md`.
- Пиши свои скрипты в `tools/` (Python 3.12 / bash), делай их повторно запускаемыми.
- Коммить часто, понятными сообщениями. Ветка `main` всегда должна собираться.
- Если решение спорное и влияет на вкус игроков — прими разумное решение сам, запиши его в
  `docs/reports/decisions.md` с альтернативой. Не жди владельца.
- Если ты упёрся в то, что можно получить только от человека (пароль, доступ к роутеру,),
  — добавь пункт в `HANDOFF.md` (раздел «Нужно от владельца») и продолжай другие задачи.
- Длинные сессии: держи `PROGRESS.md` актуальным, чтобы после `/compact` или новой сессии
  продолжить без потерь.

## 3. Структура репозитория (целевая)

```
arkhaven/
├─ CLAUDE.md, PROGRESS.md, HANDOFF.md, README.md
├─ docs/                     # ТЗ (этот комплект) + reports/ (твои отчёты)
├─ pack/                     # packwiz: pack.toml, index.toml, mods/*.pw.toml
│  ├─ config/                # конфиги модов (тюнинг баланса и производительности)
│  ├─ defaultconfigs/        # серверные конфиги по умолчанию для новых миров
│  ├─ kubejs/                # server_scripts, startup_scripts, client_scripts, assets/lang
│  ├─ config/ftbquests/      # квесты (SNBT)
│  ├─ resourcepacks/ shaderpacks/  # только через packwiz (ссылки), не бинарники
│  └─ options.txt, servers.dat (шаблоны клиента)
├─ core-mod/                 # исходники мода arkhaven-core (NeoForge MDK, Java 21)
├─ launcher/                 # сборка exe: Prism portable + Inno Setup скрипт + иконки
├─ server/                   # docker-compose, systemd, скрипты деплоя/бэкапа
├─ tests/                    # тестовые миры, сценарии, валидаторы
├─ tools/                    # утилиты: проверка сторон, дубликатов, ссылок, дамп реестров
└─ .github/workflows/        # CI (если владелец дал GitHub)
```

## 4. Definition of Done всего проекта

Проект готов, когда выполнены ВСЕ пункты `docs/09_ROADMAP.md` §«Финальный DoD», в частности:
игрок на Windows запускает `Arkhaven-Setup.exe`, входит в аккаунт Microsoft, жмёт «Играть» —
и оказывается на домашнем сервере с актуальной версией сборки, русским языком, красивой графикой
по умолчанию и первым квестом на экране. Без единого ручного шага, кроме входа в аккаунт.

В конце создай `HANDOFF.md` для владельца: что получилось, как зайти, какие пресеты графики,
что проверить глазами, известные ограничения, как обновлять, как восстанавливать бэкап.
