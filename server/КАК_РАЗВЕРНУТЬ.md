# Arkhaven — как поднять сервер

Два варианта: **ноутбук на Linux** (рекомендуется, работает в фоне через Docker) или **твой ПК на Windows**.
В обоих случаях друзья в той же сети видят сервер сами: игра подключится автоматически, а ещё он появится
в «Сетевой игре → Локальная сеть». Вход — через аккаунт Microsoft (лицензия), как обычно.

Перед началом нужен **адрес пакета** (`pack.toml`) — ссылка на GitHub Pages, которую я настрою, когда будет репозиторий.
Дальше в тексте это `PACK_URL`.

---

## Вариант 1. Ноутбук на Linux (Ubuntu / Debian / Mint)

Требования: 16 ГБ ОЗУ и больше (лучше 32), SSD, ноутбук подключён к роутеру (лучше кабелем) и **не уходит в сон**.

1. Скопируй папку `server` из архива на ноутбук, открой в ней терминал.
2. Установка (один раз):
   ```bash
   bash scripts/install.sh
   ```
   Скрипт поставит Docker (если его нет), создаст пользователя `arkhaven` и папку `/opt/arkhaven`,
   включит автозапуск, ночной рестарт в 06:00 и ежечасные бэкапы. Другие программы не трогает.
3. Впиши настройки:
   ```bash
   sudo nano /opt/arkhaven/compose/.env
   ```
   - `PACK_URL=` — ссылка на пакет;
   - `OPS=ТвойНик` — кто админ;
   - `WHITELIST=Ник1,Ник2,Ник3` — кто может заходить;
   - `SERVER_MEMORY=10G` (на ноутбуке с 16 ГБ — `8G`).
4. Запусти: `sudo systemctl restart arkhaven`. Первый старт 3–5 минут (скачиваются моды).
5. Чтобы ноутбук не засыпал при закрытой крышке:
   ```bash
   sudo sed -i 's/^#\?HandleLidSwitch=.*/HandleLidSwitch=ignore/' /etc/systemd/logind.conf && sudo systemctl restart systemd-logind
   ```

Полезное:
| Что | Команда |
|---|---|
| Логи | `docker logs -f arkhaven-mc` |
| Консоль сервера | `docker exec -it arkhaven-mc rcon-cli` |
| Добавить игрока | в консоли: `whitelist add Ник` |
| Сделать бэкап сейчас | `docker exec arkhaven-backup backup now` |
| Откатить мир | `sudo /opt/arkhaven/scripts/restore.sh latest` (старый мир сохраняется рядом) |
| Остановить / запустить | `sudo systemctl stop arkhaven` / `sudo systemctl start arkhaven` |

## Вариант 2. Твой ПК на Windows

Удобно, если сервер нужен, только когда ты сам за компьютером. Docker не нужен.

1. Открой PowerShell **от имени администратора** в папке `server\windows` из архива.
2. Выполни (подставь ссылку):
   ```powershell
   powershell -ExecutionPolicy Bypass -File install.ps1 -PackUrl ССЫЛКА_НА_PACK_TOML
   ```
   Поставит Java 21 и сервер NeoForge в `C:\Arkhaven`, откроет порты 25565 и 24454 **только для домашней сети**,
   добавит ежечасный бэкап (`C:\Arkhaven\backups`) и автозапуск при входе в Windows.
3. Запусти `C:\Arkhaven\start.cmd`. В открывшемся окне — консоль сервера:
   - `op ТвойНик`, `whitelist add Ник` — права и белый список;
   - `stop` — остановить (сервер перезапустится сам; чтобы не перезапускался — создай файл `C:\Arkhaven\stop.flag`).
4. Память: если ПК играет и держит сервер одновременно — оставь серверу 8–10 ГБ (по умолчанию 10 ГБ,
   поменять: `install.ps1 ... -Memory 8G`).

⚠ Сервер на том же ПК, где ты играешь, забирает 2–4 ядра процессора — FPS в игре будет ниже, чем с сервером на ноутбуке.

## Как друзья подключаются

- **В одной сети (дома, через один роутер):** ставят `Arkhaven-Setup.exe`, входят в аккаунт Microsoft, жмут «Играть» —
  лаунчер сам найдёт сервер в сети и подключится.
- **Через интернет:** нужен проброс порта 25565/TCP (и 24454/UDP для голоса) на роутере на IP сервера,
  или бесплатный туннель playit.gg. Напиши — настрою и впишу адрес в установщик.

## Обновления сборки

Я публикую новую версию в GitHub → игроки получают её при следующем запуске игры, сервер — при перезапуске
(`sudo systemctl restart arkhaven` или перезапуск `start.cmd`). Переустанавливать ничего не нужно.
