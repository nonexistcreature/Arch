# Arkhaven — как поднять сервер

Два варианта: **твой ПК на Windows** (один двойной клик) или **ноутбук на Linux** (работает в фоне через Docker).
В обоих случаях:

- сборка скачивается сама с `https://nonexistcreature.github.io/Arch/pack.toml` и обновляется при каждом перезапуске;
- сервер **объявляет себя в локальной сети**: игроки дома подключаются автоматически;
- сервер **поднимает свою сеть ZeroTier** (виртуальная локалка через интернет): друзья из других городов
  подключаются так же автоматически. Аккаунт на zerotier.com не нужен, роутер настраивать не нужно;
- вход — через аккаунт Microsoft, как обычно.

---

## Вариант 1. Твой ПК на Windows — без ручных шагов

1. Распакуй `Arkhaven-Server-Kit.zip` (или открой папку `server\windows` в репозитории).
2. Дважды кликни **`Arkhaven-Server-Setup.cmd`** и нажми «Да» на запрос прав администратора.

Дальше всё делается само (10–15 минут при первом запуске):

| Что | Где |
|---|---|
| Java 21 и сервер NeoForge 21.1.259 | `C:\Arkhaven` (больше на ПК ничего не ставится, кроме ZeroTier) |
| Моды, конфиги, квесты, KubeJS | скачиваются packwiz при каждом старте сервера |
| Админ (op) | **ты**: скрипт берёт ник из аккаунта, в который ты уже вошёл в лаунчере Arkhaven/Prism/официальном |
| Сеть друзей ZeroTier | создаётся на этом ПК, адрес сервера в ней — **10.77.0.1** |
| Порты 25565/TCP, 24454/UDP | открыты только для домашней сети и подсети ZeroTier 10.77.0.0/24 |
| Бэкап мира | каждый час в `C:\Arkhaven\backups` (все за последние сутки + по одному за 7 дней) |
| Автозапуск | при входе в Windows; после падения сервер перезапускается сам через 10 секунд |

После установки откроется окно консоли сервера. Первый старт — 3–5 минут.

Если скрипт запущен из папки репозитория, ID сети ZeroTier записывается в `pack/network.json`.
После публикации (git push) установщики игроков берут его оттуда сами.

**Консоль сервера** (то самое окно):
- `stop` — остановить (сервер перезапустится сам; чтобы не перезапускался, создай файл `C:\Arkhaven\stop.flag`);
- `op Ник` — дать админку ещё кому-то;
- `whitelist on` + `whitelist add Ник` — включить белый список (нужно, только если откроешь порт в интернет).

Память: по умолчанию 10 ГБ. Если играешь на этом же ПК — так и оставь; иначе можно больше:
`powershell -ExecutionPolicy Bypass -File install.ps1 -Memory 14G` (повторный запуск безопасен, мир не трогается).

⚠ Сервер на том же ПК, где ты играешь, забирает 2–4 ядра процессора, поэтому FPS будет ниже, чем с сервером на ноутбуке.

## Вариант 2. Ноутбук на Linux (Ubuntu / Debian / Mint)

Требования: 16 ГБ ОЗУ и больше, SSD, ноутбук подключён к роутеру (лучше кабелем) и **не уходит в сон**.

1. Скопируй папку `server` из архива на ноутбук, открой в ней терминал.
2. Установка (один раз):
   ```bash
   bash scripts/install.sh
   ```
   Скрипт сам поставит Docker и ZeroTier, создаст пользователя `arkhaven` и папку `/opt/arkhaven`,
   сгенерирует пароль RCON, включит автозапуск, ночной рестарт в 06:00, ежечасные бэкапы и поднимет
   сеть друзей (сервер — **10.77.0.1**, ID сети — в `/opt/arkhaven/zerotier_network.txt`). Другие программы не трогает.
3. Если нужно, поправь `/opt/arkhaven/compose/.env` (`OPS=ТвойНик`, `SERVER_MEMORY=10G`; на ноутбуке с 16 ГБ — `8G`),
   потом `sudo systemctl restart arkhaven`.
4. Чтобы ноутбук не засыпал при закрытой крышке:
   ```bash
   sudo sed -i 's/^#\?HandleLidSwitch=.*/HandleLidSwitch=ignore/' /etc/systemd/logind.conf && sudo systemctl restart systemd-logind
   ```
5. ID сети отсюда положи в `pack/network.json` репозитория (`{"zerotier": "<id>", "server": "10.77.0.1"}`)
   и запушь: установщики игроков возьмут его сами.

| Что | Команда |
|---|---|
| Логи | `docker logs -f arkhaven-mc` |
| Консоль сервера | `docker exec -it arkhaven-mc rcon-cli` |
| Бэкап сейчас | `docker exec arkhaven-backup backup now` |
| Откатить мир | `sudo /opt/arkhaven/scripts/restore.sh latest` (старый мир сохраняется рядом) |
| Остановить / запустить | `sudo systemctl stop arkhaven` / `sudo systemctl start arkhaven` |
| Кто в сети ZeroTier | `sudo zerotier-cli listpeers` |

## Как друзья подключаются

| Кто | Что делает |
|---|---|
| Новый игрок | ставит `Arkhaven-Setup.exe`, оставляет галочку «подключить сеть друзей (ZeroTier)», входит в Microsoft, жмёт «Играть» |
| Играет в Prism / MultiMC | «Добавить экземпляр → Импорт» → `Arkhaven-Prism-Instance.zip` |
| Официальный лаунчер или другой со стандартной папкой .minecraft | распаковывает `Arkhaven-Own-Launcher.zip`, запускает `install-to-launcher.cmd` |

Перед каждым запуском игра ищет сервер: сначала в локальной сети и на этом же ПК, потом по ZeroTier (10.77.0.1).
Подробнее для игроков — `launcher/ИГРОКАМ.md`.

**Без ZeroTier, через интернет:** проброс 25565/TCP (и 24454/UDP для голоса) на роутере или туннель playit.gg.
В этом случае обязательно включи белый список (`whitelist on`).

## Обновления сборки

Новая версия публикуется в GitHub (push в `main`). Игроки получают её при следующем запуске игры,
сервер — при перезапуске. Переустанавливать ничего не нужно.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| Друг издалека не видит сервер | у друга: `zerotier-cli listnetworks` (статус OK, адрес 10.77.0.x); если ZeroTier не стоит — запустить `zerotier-join.ps1` из папки Arkhaven |
| «Не удалось подключиться» дома | проверить, что окно сервера открыто и в нём написано `Done`; Windows-брандмауэр: сеть роутера должна быть «Частной» |
| Сервер долго стартует | первый старт качает ~1 ГБ модов, это нормально |
| Нужно откатить мир (Windows) | остановить сервер, распаковать нужный zip из `C:\Arkhaven\backups` в `C:\Arkhaven\server\world` |
